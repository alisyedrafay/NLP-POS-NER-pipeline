# NLP POS Tagging & Named Entity Recognition

This repository demonstrates an **end-to-end Natural Language Processing (NLP) pipeline** focusing on **Part-of-Speech (POS) Tagging** and **Named Entity Recognition (NER)** using Python. The project is beginner-friendly and suitable for academic projects, learning NLP fundamentals, and showcasing practical NLP skills.

---

## 📌 Features

* Text preprocessing and tokenization
* Part-of-Speech (POS) tagging
* Named Entity Recognition (NER)
* Clean and simple Python implementation
* Uses industry-standard NLP libraries

---

## 🛠️ Tech Stack

* Python 🐍
* spaCy / NLTK
* Jupyter Notebook / Python scripts

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/nlp-pos-ner-pipeline.git
cd nlp-pos-ner-pipeline
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Download spaCy model (if using spaCy)

```bash
python -m spacy download en_core_web_sm
```

---

## ▶️ Usage

### POS Tagging

```bash
python src/pos_tagging.py
```

### Named Entity Recognition

```bash
python src/ner.py
```
